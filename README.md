# RAM Solutions Multi-page Website

A responsive, static multi-page company website designed for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About RAM Solutions
- `services.html` — Services
- `projects.html` — Project categories / case-study placeholders
- `contact.html` — Contact details

## Assets
- `assets/style.css` — Responsive design and page styling
- `assets/script.js` — Mobile navigation and current footer year
- `RAM Logo.png` — Existing repository logo, referenced from the repository root
- `RAM 1X1.png` — Existing favicon, referenced from the repository root

Keep the two existing image files in the repository root with the exact filenames above. If your current files have different names, update the references in each HTML file.

## Publish with GitHub Pages
The current repository is configured to publish from the `main` branch and repository root. Upload/replace the HTML files and the `assets/` folder in the repository root, then commit the changes to `main`.

## Notes
- This is a static website; it does not run PHP or require a database.
- Update the service/project copy to match confirmed company offerings and approved case studies.
- Contact emails are set to `contact@ramsolutions.asia` and `info@ramsolutions.asia`.

## Custom domain
The `CNAME` file contains `ramsolutions.asia`. Keep it in the repository root for GitHub Pages custom-domain configuration.

The existing `RAM Logo.png` is used in the header and footer on every page; `RAM 1X1.png` is used as the favicon. Keep both files in the repository root.
